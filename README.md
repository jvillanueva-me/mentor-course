# Supercharging Your Career With the Help of a Mentor

A self-paced, six-lesson online course for early- to mid-career professionals who want to find a good mentor and become an effective mentee.

It's a single static page (`index.html`) with no build step. Open it in a browser, or host it with GitHub Pages.

- Lessons: What Is Mentoring?, Limitations of Mentors, How Do I Find a Mentor?, Attitudes and Habits of Effective Mentees, Common Mentoring Challenges, and Summary
- Activities: a step-by-step reveal, drag-or-tap sorting, flip cards, a mentor match tool, a habit checklist, a scenario coach and an action-plan builder
- Progress and notes are saved in the learner's own browser (localStorage)
